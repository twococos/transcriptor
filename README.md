# Transcriptor

Donada una cançó (URL de YouTube o fitxer d'àudio), n'extreu lletra, acords,
tonalitat, tempo, compassos i seccions, i genera el `content` amb `<ch>`/`<sec>`
per a l'editor d'El Cançoner (guitarreo.cat).

- Pla complet: [PLAN_TRANSCRIPCIO.md](PLAN_TRANSCRIPCIO.md)
- Proves d'eines (Fase 0): [docs/proves.md](docs/proves.md)

Requisit: tot s'ha d'instal·lar a Windows amb `uv`, sense Docker i sense compilar res.
